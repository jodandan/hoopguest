# 연습경기 초청/원정 구분 + 연습경기 알림 (2026-10-22)

## 배경
- 지인 인터뷰 1건: 대회 준비 팀이 연습경기 상대를 찾고 싶어 함(불편점은 미확인 — 가정).
- 연습경기 글: 28일 855건, 최근 7일 155건 중 '초청' 132 / 원정·구함 18. 주말 65%.

## 결정 (사용자 확정)
- 연습경기 탭에 칩 [전체 · 초청 · 원정]
- 제목에 초청/원정 표현이 없으면 **초청**으로 분류
- 배포는 QA 통과 → 사용자 승인 → 리드가 푸시

## 작업
### backend (parser.mjs, worker/worker.js)
1. `parser.mjs`: 연습경기 글(board=match)에 `kind: 'host' | 'away'` 추가
   - away: 제목에 `원정`, `구합니다`, `구해요`, `찾습니다`, `찾아요` (단 `초청`이 같이 있으면 host)
   - 그 외 전부 host
   - 연습경기가 아닌 글에는 `kind`를 넣지 않음
2. `worker/worker.js` `matches()`·`cleanFilters()`: 필터 `kind`(`'host'|'away'|''`) 지원. `p.kind`가 없는 글은 통과(옛 데이터 호환)
3. 확인: 지금 `docs/data.json` 연습경기 글로 분류 결과 수(host/away)와 away 예시 전부를 리드에게 보고 → 사용자 승인 후 다음 단계

### frontend (docs/index.html, docs/sw.js)
1. 연습경기 탭에서만 [전체·초청·원정] 칩 표시. 다른 탭에선 숨김. 칩 숫자 = 목록 건수(기존 칩 규칙과 같게)
2. 연습경기 탭 목록 위에 "이 조건으로 알림 받기" 버튼 → 맞춤 알림 창을 `글 종류=연습경기, 지금 지역, kind=지금 칩` 으로 미리 채워 열기. 로그인 안 했으면 기존 종(알림) 창 흐름
3. `docs/sw.js` `matches()`에도 `kind` 조건 추가(worker와 같은 규칙). CACHE 이름 bdr-v9 → bdr-v10
4. GA: `match_kind`(kind=all|host|away), `alert_preset`(from=match)
5. 카드에 '원정' 작은 꼬리표(초청은 표시 안 함 — 대부분이라 시끄러움)

### qa
- 320·360·390·가로·PC × 밝게/어둡게: 칩 줄 넘침, 버튼 터치 영역 32px 이상
- 연습경기 탭 ↔ 다른 탭 전환 시 칩 숨김/복원, 새로고침 후 선택 유지 여부
- 알림 버튼 → 미리 채워진 값 확인(로그인/비로그인 둘 다)
- worker `matches()` 단위 테스트: kind 없음/host/away × 필터 없음/host/away
